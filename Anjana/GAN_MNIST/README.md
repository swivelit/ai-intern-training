
# Project 13: GAN – Generate Handwritten Digits

## Dataset
MNIST handwritten digits

## Objective
Build and train a simple GAN to generate handwritten digits.

## Output
- Generator learns digit structure
- Saved images every few epochs (PNG)
- Upload generated images to GitHub

## Run Instructions
```bash
pip install -r requirements.txt
python gan_mnist.py
```

## Notes
- Training longer improves digit quality
- Generated images are saved automatically
