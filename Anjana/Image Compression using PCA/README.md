
# Image Compression using PCA

This project demonstrates image compression using Principal Component Analysis (PCA).

## Features
- Load CIFAR-10 images
- Apply PCA for dimensionality reduction
- Reconstruct compressed images
- Compare original vs reconstructed images visually

## Requirements
- numpy
- matplotlib
- scikit-learn
- torchvision
- torch

## Run
```bash
python pca_image_compression.py
```
