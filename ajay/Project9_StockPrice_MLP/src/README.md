# Project 9: Stock Price Prediction with MLP (Regression)

## Goal
Train a regression **MLP** to predict the **next-day closing price** using a Yahoo Finance historical CSV.

## Dataset
- Yahoo Finance Historical Data CSV (user-selected stock)

## Features
Uses past N days (lookback window) of:
- Open, High, Low, Close, Volume

Target:
- Next-day Close
