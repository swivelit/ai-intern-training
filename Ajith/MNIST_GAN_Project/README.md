
# MNIST GAN – Handwritten Digit Generation

## Objective
Generate handwritten digits using a simple GAN trained on MNIST.

## Steps
1. Install dependencies:
   pip install torch torchvision matplotlib
2. Run training:
   python src/train_gan.py
3. Generated images will appear in `generated_images/`

## Output
- Recognizable handwritten digits
- Generator & Discriminator trained using GAN framework
