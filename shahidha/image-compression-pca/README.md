# Image Compression using PCA

## Description
This project demonstrates image compression using Principal Component Analysis (PCA).
Images are compressed by reducing dimensionality and reconstructed for comparison.

## Dataset
CIFAR-10 dataset from TensorFlow.

## Steps
1. Load images
2. Flatten image vectors
3. Apply PCA
4. Reconstruct images
5. Compare original vs compressed

## Result
Compressed images retain structure with reduced data size.

python run.py
