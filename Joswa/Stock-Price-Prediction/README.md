# Stock Price Prediction using MLP

## Objective
Predict next-day closing price using MLP neural network.

## Dataset
Yahoo Finance historical stock data.

## Model
- MLP (Dense layers)
- Input: Previous 5 days prices
- Output: Next day price

## Steps
1. Data preprocessing
2. Scaling
3. Train MLP model
4. Predict
5. Plot results

## Output
- predictions.csv
- plot.png
