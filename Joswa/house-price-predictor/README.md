# 🏠 House Price Predictor

## 📌 Overview

This project predicts house prices using machine learning models on the California Housing dataset.

## 📊 Models Used

* Linear Regression
* Polynomial Regression
* Decision Tree Regressor
* Random Forest Regressor

## 📈 Evaluation Metrics

* RMSE (Root Mean Squared Error)
* MAE (Mean Absolute Error)

## 🚀 How to Run

```bash
pip install -r requirements.txt
python main.py
```

## 📊 Sample Output

```

  MAE : 0.5332

Polynomial Regression:
  RMSE: 0.6821
  MAE : 0.4903
```

## 📌 Conclusion

Random Forest gives the best performance among all models.
