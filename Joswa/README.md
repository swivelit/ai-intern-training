# Loan Approval Prediction

## 📌 Description
Predict whether a loan should be approved using Machine Learning models.

## 🚀 Models Used
- Decision Tree
- Random Forest
- XGBoost
- LightGBM
- CatBoost

## 📊 Features
- Data preprocessing
- Multiple model comparison
- Feature importance visualization
- Best model selection

## ▶️ How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Place dataset:
   data/loan_data.csv

3. Run:
   python main.py

## 📁 Output
- model.pkl (best model)
- feature_importance.png
- results.txt
