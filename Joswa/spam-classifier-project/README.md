
# Email Spam Classifier

## Description
This project builds a spam email classifier using:
- Logistic Regression
- SVM
- KNN
- Naive Bayes

## Dataset
Download from UCI:
https://archive.ics.uci.edu/ml/datasets/spambase

Place `spambase.data` inside the `data/` folder.

## Run
```bash
pip install -r requirements.txt
python main.py
```

## Output
- Accuracy scores
- Confusion matrix images
- ROC curves
