# Image Compression using PCA

## 📌 Objective
Reduce image size using PCA and reconstruct it.

## 📂 Dataset
Custom images or CIFAR-10

## ⚙️ Steps
- Load images
- Apply PCA on RGB channels
- Reduce dimensions
- Reconstruct images

## 📊 Output
- Original images
- Reconstructed images
- Visual comparison

## ▶️ Run
```bash
python main.py
