
FrozenLake Q-Learning Agent

Steps to run:
1. Install dependencies:
   pip install gym numpy matplotlib

2. Train agent:
   python train.py

3. View reward curve:
   plots/reward_curve.png

4. Demonstrate trained agent:
   python demo.py

Outputs:
- models/q_table.npy (trained Q-table)
- plots/reward_curve.png
