# House Price Predictor

### Models Implemented
- Linear Regression
- Polynomial Regression
- Decision Tree Regressor
- Random Forest Regressor

### Evaluation Metrics
Models are compared using:
- RMSE (Root Mean Squared Error)
- MAE (Mean Absolute Error)

See `notebooks/model_training.ipynb` for results and visualizations.

### Usage
Train models:
```
python src/train.py
```

Predict sample:
```
python src/predict.py
```

### Dataset
Uses **Boston Housing** or **California Housing** dataset from scikit-learn (built‑in).
