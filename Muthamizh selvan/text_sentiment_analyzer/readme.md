# 🧠 Text Sentiment Analyzer (LSTM vs GRU)

A Deep Learning project that compares **LSTM** and **GRU** models for movie review sentiment classification using the IMDB dataset.

Built fully compatible with **Python 3.13** using:

- PyTorch
- HuggingFace Datasets
- Pure Python preprocessing

---

## 📌 Project Objective

- Load IMDB movie review dataset
- Build vocabulary from scratch
- Train LSTM model
- Train GRU model
- Compare accuracy
- Evaluate performance

---

## 🛠 Tech Stack

- Python 3.13
- PyTorch
- HuggingFace `datasets`
- NumPy
