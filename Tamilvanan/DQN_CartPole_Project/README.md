
# DQN – CartPole Balancing

## Environment
OpenAI Gym: CartPole-v1

## Goal
Train a Deep Q-Network (DQN) from scratch to achieve **average reward ≥ 200**.

## Files
- `train.py` – Train DQN and save model + reward plot
- `dqn.py` – DQN neural network
- `replay_buffer.py` – Experience replay buffer
- `requirements.txt` – Dependencies
- `saved/` – Trained model weights & plots

## Run
```bash
pip install -r requirements.txt
python train.py
```
