
# CIFAR-10 Image Compression using PCA

## Description
This project applies **Principal Component Analysis (PCA)** to compress CIFAR-10 images.

## Steps
1. Load CIFAR-10 dataset
2. Convert image to grayscale
3. Apply PCA for dimensionality reduction
4. Reconstruct and compare images

## Requirements
- Python 3.x
- numpy
- matplotlib
- scikit-learn
- tensorflow

## Run
```bash
python main.py
```

## Output
Displays original and PCA-compressed CIFAR-10 image.
