
# GAN – Handwritten Digit Generation (MNIST)

## Objective
Build and train a simple Generative Adversarial Network (GAN) to generate handwritten digits using the MNIST dataset.

## Steps
1. Load MNIST dataset
2. Build Generator and Discriminator
3. Train GAN until digits become recognizable
4. Save generated images per epoch

## Run
```bash
pip install torch torchvision
python main.py
```

## Output
Generated images will be saved in `generated_images/`.
