# Loan Approval Prediction

This project focuses on predicting loan approval status using various machine learning models, specifically Decision Trees and Ensemble methods.

## Dataset
The dataset contains information about loan applicants, including gender, marital status, education, income, and loan history.

## Models Implemented
- **Decision Tree**
- **Random Forest**
- **XGBoost**
- **LightGBM**
- **CatBoost**

## Goal
To achieve a prediction accuracy of **>80%** using ensemble techniques.

## Setup
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the prediction script:
   ```bash
   python loan_approval_prediction.py
   ```
